# 📋 Registro de Órdenes de Trabajo Diario

> Sistema de registro de órdenes de trabajo con reporte listo para compartir por WhatsApp.

## 🚀 Acerca de este proyecto
Herramienta práctica para llevar el control diario de órdenes de trabajo, generar resúmenes rápidos y compartirlos directamente por WhatsApp.

✅ Registro diario de órdenes
✅ Generación de reporte automático
✅ Botón para compartir por WhatsApp
